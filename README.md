# decal-assets
Public art assets related to Vertek decals. 

Shared assets for the Vertek decal media pipeline skill.

- `decal-frame-transparent.png`: chrome tap frame (583x1024 RGBA, transparent screen hole) used to build customer preview images and videos.
  Raw URL: https://raw.githubusercontent.com/VertekAU/decal-assets/main/decal-frame-transparent.png
- `build_preview.py`: customer preview builder (decal art in the tap frame over a bar backdrop, watermarked). Downloads the frame above by default.
  Raw URL: https://raw.githubusercontent.com/VertekAU/decal-assets/main/build_preview.py
